# Keys

Press `?` in Jiary to see these keys, or `/` to find an action by name.

## Recording

| Key | Action |
|-----|--------|
| `s` | Start a session |
| `e` | End the running session |
| `1` `2` `3` | Rate your focus, within 5 seconds of a session ending |
| `u` | Undo the last start or end |
| `p` | Turn the Pomodoro on or off |
| `n` | Add a note to the running session |
| `i` | Count an interruption |
| `d` | Start a disruption (needs a running session) |
| `b` | Start a break |
| `m` | Start a meeting |
| `r` | Resume the last work session, ending a disruption, break or meeting |
| `[` / `]` | Move the running session's start 5 minutes earlier / later |
| `/` | Open the command palette |
| `?` | Show all keys |
| `q` / `Ctrl+C` | Quit |

See [Recording your day](recording.md).

## The main screen

| Key | Action |
|-----|--------|
| `Tab` / `Shift+Tab` | Focus the next / previous section |
| `Space` | Collapse or expand the focused section (Today and Summary) |
| `+` / `-` | Grow or shrink the focused section |
| `=` | Reset section sizes to fit their content |
| `↑` `↓` / `j` `k`, `PgUp` `PgDn`, `Home` `End` | Scroll the focused section |

See [The main screen](main-screen.md), which also covers the mouse.

## Rewind (`/rewind`)

| Key | Action |
|-----|--------|
| type | Search (see [Rewind](looking-back.md#rewind-every-past-day-searchable)) |
| `↑` `↓` (or the wheel), `PgUp` `PgDn`, `Home` `End` | Pick a day |
| `Enter` | Open the picked day |
| `Esc` | Clear the search; on an empty search, close |

In an opened day:

| Key | Action |
|-----|--------|
| `←` `→` / `h` `l` | The older / newer day in the list |
| `↑` `↓` / `j` `k`, `PgUp` `PgDn`, `Home` `End` | Scroll |
| `Esc` / `q` | Back to the list |

## Settings (`/settings`)

| Key | Action |
|-----|--------|
| `↑` `↓` / `j` `k` | Pick a setting |
| `Space` / `Enter` / `→` | Change it (the target: 5 minutes longer) |
| `←` | Change it the other way (the target: 5 minutes shorter) |
| `Esc` / `q` | Close |

See [Settings](recording.md#settings).

## Sleep and mood

Asked by the day's first `s`, or by `/mood`.

| Key | Action |
|-----|--------|
| `1` `2` `3` | Answer the question (sleep, then mood) |
| `Enter` | Leave the answer as it is |
| `Backspace` | Back to sleep |
| `Esc` | Skip for today (or, from `/mood`, cancel) |

`/mood-off` stops asking, and `/mood-on` starts again. See
[Sleep and mood](recording.md#sleep-and-mood).

## The start form

| Key | Action |
|-----|--------|
| `1`–`5` | Start a recent combination (while the activity is empty) |
| `Tab` / `↓` | Pick the next suggestion |
| `↑` | Pick the previous suggestion, or go back to what you typed |
| `Enter` | Confirm the step (an empty project or task skips it) |
| `Esc` | Close the form |

## Renaming (`/rename`)

| Key | Action |
|-----|--------|
| `↑` `↓` / `Tab` | Pick activity, project or task (first step) |
| `Tab` / `↓`, `↑` | Pick a suggestion (other steps) |
| `Enter` | Next step, then apply |
| `Esc` | Cancel; nothing is written before the last `Enter` |

See [Renaming and merging names](recording.md#renaming-and-merging-names).

## Back from an absence (or Jiary closed)

| Key | Action |
|-----|--------|
| `k` / `Esc` | Keep the time away as part of the session |
| `b` | Count it as a break, then carry on (not for a detour) |
| `d` | Count it as a disruption, then carry on (not for a detour) |
| `e` | End the session when you left (or closed Jiary) |

## The longer views

| Key | Action |
|-----|--------|
| `←` `→` / `h` `l` | The period before / after |
| `w` `m` `y` | This week, month or year |
| `↑` `↓` / `j` `k`, `PgUp` `PgDn`, `Home` `End` | Scroll (or the mouse wheel) |
| `Esc` / `q` | Back to the main screen |

See [Looking back](looking-back.md).
